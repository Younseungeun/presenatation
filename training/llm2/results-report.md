# 로컬 소형 LLM 2단 검수 — 실측 결과표 (36차 MM-1, 2026-08-27)

검토자 최종 판정용. 등록된 잣대 4종 전건 실측, GBNF 문법 강제 상태, 전부 zero-shot
(few-shot 은 등록된 1회 재측정 축 — 예시 2개, 채점지 밖 문장).

## 반증 조건 판정 (등록 원문 대비)

- ① 처리량 미달 — **측정 생략** (③ 성립으로 폐기가 먼저 확정, 잴 실익 없음)
- ② 형식 붕괴 (문법 강제 후 JSON < 95%) — **미실현**: 전 런 **100%** (GBNF 강제 유효)
- ③ 오탐 폭발 (부정형 오탐 > P1-A) — **실현**: 전 설정에서 6~124건 vs P1-A 3건

**→ 등록된 처분: 트랙 폐기, 현 3겹(규칙 + IRIS + 운영자) 유지.**

## 부수 관측 (기록 — 처분 근거 아님)

- **패러프레이즈**(같은 뜻 다른 말, 규칙 0%·채점지): Qwen3-4B s2 가 **19/24 (79%)** —
  LLM 의 문맥 이해력 자체는 실재한다. 죽인 것은 능력이 아니라 **부정형 정밀도**다:
  r6 의 하드네그(위반을 부정·부인하는 대비쌍)를 zero/few-shot LLM 이 "위반 어휘가
  보이면 지적"으로 처리한다. IRIS 는 이 구분을 1,000문장 학습으로 익혔다 —
  **학습 없이 프롬프트만으로는 이 잣대를 못 넘는다**는 것이 이번 실측의 요지
- CARD_MISMATCH (본문-카드 모순): 최고가 Qwen 4B s2 의 21건 중 2건 — 사실상 전멸.
  NLI 몫이라는 기존 결론 유지
- 형식·인프라: GBNF 직접 작성으로 4모델 전부 JSON 100% (검토자의 GBNF 지시가 옳았다).
  자동 변환(json_schema) 경로는 b10643 에서 Gemma·Kanana 와 충돌 — GBNF 원문 전달로 해결
- 재측정 소요: 모델당 5~10분(GPU), Kanana 1회차만 82분(재시도 폭주) — 기록만

## 남는 길 (등록 로드맵 그대로)

정확도 상향의 1순위였던 **운영 데이터 경로(LL-3)**가 유일하게 남는다. 출시 → 운영
라벨 축적 → 재학습. LLM 트랙의 재개 조건은 새 사전 등록뿐이며, 이번 실측이 남긴
단서(부정형 정밀도가 병목, 능력은 실재)는 그때의 출발점이 된다 — 예: 운영 라벨
수백 건으로 소형 LLM 을 LoRA 미세조정하는 안건은 "학습 없는 프롬프트"와 다른 트랙이다.
