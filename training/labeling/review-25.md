# 25차 검토 요청 — 24차 처방에 대한 이행 계획 판정. 실측 2건이 판을 바꿨습니다

## 0. 지난 회차 이후 — "먼저 재야 할 것" 둘을 즉시 쟀습니다

24차 답변의 처방을 그대로 이행하기 전에, 여러분이 요구한 실측 2건을 먼저
돌렸습니다. **둘 다 처방의 전제를 흔들었습니다.**

### 실측 ① 부분 뇌사 가설 — 반증됨

명백한 PRIVATE_INFO 위반 5문장을 라이브 r5(a0eaa12a)에 실투:

```
"지인이 IR팀… 공시 안 된 3분기 실적을 미리"   PRIVATE_INFO 0.855  ✓ 탐지 (t=0.7)
"내부 관계자에게 확인한 미공개 정보… 무조건"   PRIVATE_INFO 0.625  침묵
"기관 매수 주문 내역을 비공개 경로로 입수"     PRIVATE_INFO 0.816  ✓ 탐지
"대표이사와의 사적인 자리에서 들은 인수합병"   PRIVATE_INFO 0.688  침묵
"증권사 친구가 알려준 미공개 리포트 초안"      PRIVATE_INFO 0.824  ✓ 탐지
```

예측하신 "0.1 이하 바닥"(헤드 사멸)은 없습니다 — **전부 0.6 이상, 5건 중 3건
탐지**. 라벨 헤드는 살아 있습니다. 원 학습셋(synth.v2 390)에 PRIVATE_INFO 표본이
있었고, r3~r5 재학습이 그것을 죽이지 않았습니다. 실제 그림은 뇌사가 아니라
**경계 둔화** — 23차 Z-1의 부정 구역(0.41 중간대)과 정확히 같은 병입니다.
침묵한 2건도 0.62~0.69로 임계 바로 밑에 떠 있습니다.

이 반증이 AA-5·AA-7의 처방을 수정합니다 (아래 BB-5·BB-7).

### 실측 ② 산문 정제 필터 — 여러분의 함정이 첫 판에서 그대로 적중

형태 기준만으로(검사기 출력 무참조) 2차 정제 필터를 짰습니다:

- **v1**: 술어 종결(다/요/까) + 조사 1회 이상 + 5어절 이상
  → **채점지 정상 3건이 찢김** ("무조건 오른다고 말하는 사람은 피하십시오" —
  전부 '…십시오' 명령형). 위반도 8건 탈락. **AA-4 함정("필터가 시험지를 찢는다")이
  이론이 아니라 첫 시도에서 실제로 일어났습니다**
- **v2**: 종결형에 '오' 추가 + 4어절로 완화
  → 채점지 **정상 29/29 전건 생존**. 위반 탈락 4건은 전부 회피·주입형
  ("수익·보·장", "몰 빵", 프롬프트 주입 영문) — 형태상 산문이 아니고 규칙 엔진
  관할이므로 학생-축 벤치에서 빠지는 게 정당하다고 봅니다

```
v2 결과: DART 2,481 → N_clean = 1,945 (78.4% 생존)
Rule of Three 기준값: 3/1,945 = 0.154%
r5 실측 오탐: 7건 (0.36%) → 기준 초과 — 현행 라이브 모델이 이 게이트를 못 넘습니다
```

오탐 7건의 해부가 중요합니다:

| 성분 | 건수 | 내용 |
|---|---|---|
| 잔여 표 조각 | 4 | 필터가 못 거른 명단·현황 나열("성명 주요 경력…", "교육일자 교육실시주체…") — 학생이 SCREENING_EVASION으로 판정 |
| 진짜 산문 | 3 | 회계 문장("현금흐름위험회피로 지정되어…") — 전부 CARD_MISMATCH |

**고정 제약 (변함없음)**: λ=4 · 운영 경로 외부 API 0회 · KoELECTRA-small 14M ·
512토큰 · 운영자 1~2인 · 채점지(69)·시드 17·홀드아웃 101·회귀셋·핑 문장 학습 금지 ·
즉시 거절은 코드 원천 패턴만

## 1. 24차 판정별 이행 계획 — 각각을 판정해 주십시오

#### BB-1. 용량 시한폭탄 — 인정하되, 그것은 "구조 변경"이 아니라고 반박합니다

14M 그릇의 한계는 실재하고, 망각의 댐 붕괴 서사도 수긍합니다. 그러나 그날 일어날
일은 **ONNX 파일 하나를 더 큰 체급으로 바꿔 끼우는 것**입니다. 관할(규칙=형태,
학생=뜻), 파이프라인(사이드카·게이트 6종·회귀셋·대장), 계약(WARN만·인용 없음)은
전부 그대로입니다. 저희 구조 동결의 정의는 "부품 교체 없음"이 아니라 "관할과
파이프라인 변경 없음"이었습니다 — 체급은 λ처럼 **파라미터**입니다.

다만 "언제 갈아 끼우나"의 트립와이어는 지금 정의해 둬야 한다는 데 동의합니다.
제안: **서로 다른 학습 런(서로 다른 sha) 3회 연속으로, 신규 자료는 배우면서 회귀
게이트에서 떨어지면** 용량 검토 개시. gateFailCount가 이미 "다른 sha에서만 +1"로
세고 있어 이 셈법과 정합합니다.

**질문**: 이 재정의(체급=파라미터)가 동결 선언의 후퇴인지, 그리고 트립와이어
"이종 sha 3연속"이 너무 늦은 발화점인지 판정해 주십시오.

#### BB-2. 완전 일치 면제 구문 — 채택하되, 등재 권한을 코드에 묶습니다

Exact Match Bypass 채택합니다. 단 한 가지를 처방에 얹습니다: **면제 구문은 코드
원천 전용입니다. 운영자 사전은 면제를 만들 수 없습니다.** 즉시 거절이 코드 원천만
갖는 이유(운영 중 실수로 거절 권한이 새는 것 방지)와 대칭으로, 거절에 구멍을 내는
권한도 코드 배포를 거쳐야 합니다. 사전이 면제권을 얻는 순간, 사전 등록 실수 한
줄이 REJECT 방어선을 조용히 무력화합니다 — λ=4에서 그 비대칭은 못 견딥니다.

구현 계획: ① 정규식 검사 직전, 면제 목록과 **완전 일치하는 절만** 시야에서 제거
② 등재 요건: 절 단위(주어+술어 포함, 최소 어절 수 하한) — "퇴직연금은" 같은
단편 등재를 형태로 차단 ③ 등재 시마다 여러분의 반증 조건 자동 실행: 위반 코퍼스
전체(채점지 위반 44 + 홀드아웃 101 + 창업자 배터리 31)에 면제 적용 후 탐지율
재측정, **1건이라도 하락하면 등재 거부**.

**질문**: 등재 권한의 코드 한정이 맞는지 — 운영자가 오탐을 발견할 때마다 배포를
기다려야 하는 비용(빠른 길 상실)과 맞바꿀 가치가 있는지 판정해 주십시오.

#### BB-3. DART 게이트 — 기준값 0.154%로 공식화하되, 판정 둘이 남았습니다

v2 필터·N_clean=1,945·기준 3건을 하드 게이트로 박겠습니다. 그런데 실측이 판정
사안 둘을 낳았습니다:

**(a) 필터 3차 조정의 경계.** 남은 오탐 7건 중 4건은 필터가 놓친 표 조각입니다.
형태 기준을 한 번 더 조이면(예: 연속 명사구 밀도) 이 4건은 사라질 것입니다 —
그러나 "오탐이 남아 있으니 필터를 조인다"를 반복하면, 형태 기준을 표방하면서
실질은 오탐 목록을 겨냥하는 Y-4형 진화가 됩니다. 저희 안: **v2에서 동결**하고,
표 조각 4건은 오탐 예산 3건 밖에 있는 채로 둡니다 — 즉 다음 재학습 모델은 이
벤치에서 3건 이하를 받아야 하고, 그러려면 표 조각을 SCREENING_EVASION으로
오인하지 않는 강건함 자체를 배워야 합니다. 필터 조정은 여기서 멈추는 게 맞습니까,
아니면 표 조각은 벤치 오염이니 형태 기준 1회 추가 조정이 정당합니까?

**(b) CARD_MISMATCH 3건의 gap 17형 의심.** 대조군 하네스는 DART 문장에 인위
카드(KR_EQUITY·UP)를 씌워 학생에 넣습니다. 그런데 공시 산문은 방향 주장이 없으니
"본문이 카드와 무관하다"는 판정은 **오탐이 아니라 정답일 수 있습니다** — 같은
지표(오탐 증가)가 "모델 열화"와 "하네스 부작용"이라는 다른 원인에서 나옵니다.
저희 안: 대조군 벤치에서 CARD_MISMATCH 라벨만 채점 제외(다른 라벨은 유지).
이러면 r5 실측은 4건이 되고, 그 4건은 전부 (a)의 표 조각입니다. 이 제외가
정당한지, 아니면 "벤치가 불리한 라벨을 빼는" 첫걸음인지 판정해 주십시오.

#### BB-4. 날짜 오탐·블로그 유도 — 그대로 이행합니다

날짜: 연락처 정규식에 부정형 전방 탐색(숫자 뒤 년/월/일/기 단위) 추가 후 창업자
배터리 31건 + 위반 코퍼스 전수 재측정으로 탐지 하락 0 확인. 블로그 유도: 규칙에
넣지 않고 다음 학습분 SOLICIT_CONTACT 대비쌍으로 — BB-5의 배분에 이미 반영.
이 항목은 판정 불요, 이행 보고만 드립니다.

#### BB-5. 다음 학습 배분 — "예방적 소생"을 "경계 선명화"로 교체합니다

실측 ①이 처방의 전제를 바꿨습니다. PRIVATE_INFO 헤드는 죽지 않았으므로 "죽은
라벨 소생 10쌍"이 아니라, 부정 구역 0.41과 **같은 처방** — 0.62~0.69 대역에 떠
있는 문장들을 0.7 위로 밀어 올리는 하드마진 대비쌍입니다. 제안 배분 (1라운드
160건 규모 유지):

- 부정 구역 하드마진 40쌍 (정상-위반이 단어 1~2개 차이 — 지시문에 명기)
- PRIVATE_INFO 경계 선명화 30쌍 (전언·간접 화법형: "지인이/친구가/자리에서 들은")
- SOLICIT_CONTACT 외부 유도형 30쌍 (블로그·카페·이웃신청 — 창업자 배터리 미탐 계열)
- 나머지 발생 0 라벨(RISK_INDUCEMENT 등) 각 10쌍 예방 주입 — 여기는 여러분
  처방을 유지합니다 (측정해 보니 살아 있었지만, 안 잰 라벨이 더 있습니다)

여러분의 부사 지름길 함정('반드시'·'결코' 암기)은 채택 후 검사에 넣습니다:
학습 후 해당 부사 제거 동의어 문장 재투로 0.4 밑 추락 여부 확인.

**질문**: 이 배분과, "경계 둔화에는 소생이 아니라 하드마진"이라는 처방 교체를
판정해 주십시오.

#### BB-6. 학습 대장 — training/ledger.jsonl, 소급 기입의 규칙 하나만 정합니다

전면 수용합니다. Git 추적 append-only 파일, 스키마는 제안하신 7칸(timestamp,
commit_sha, data_sources_with_hash, epochs, hyperparams, result_eval_metrics,
onnx_sha) 그대로. 남은 판정 하나: **r3~r5 과거 런의 소급 기입**입니다. 아카이브
(out/archive/)에서 재구성 가능한 칸만 채우고, 재구성 불가능한 칸(소실 원본의
설정 등)은 **비운 채 `retroactive: true` 표기**를 제안합니다 — 대장의 가치는
완전성이 아니라 위조 불가능성이고, 비어 있는 칸이 "여기서 소실 사고가 났다"는
기록 그 자체입니다. 맞습니까?

#### BB-7. N-핑 — 8문항으로 확정하되, 핑 문장의 자격 요건을 하나 추가합니다

수용합니다: PROFIT_GUARANTEE·RUMOR·SOLICIT_CONTACT·PRIVATE_INFO 4라벨 ×
(위반 1 + 정상 1) = 8문항. 실측 지연 4~25ms/건이라 프로세스당 1회 비용은 말씀대로
공짜입니다.

다만 실측 ①이 핑 문장의 자격 요건을 하나 가르쳐 줬습니다: 핑은 **뇌사 감지기**지
경계 감시기가 아닙니다. 0.62~0.69짜리 경계 문장을 핑으로 쓰면 정상 학습(경계
재조정)에도 오경보가 나서 밸브·HOLD가 남발됩니다. 요건: **핑 문장은 실측 마진
0.85 이상(위반) / 0.15 이하(정상)로 여유 통과하는 문장만**, 채택 시마다 재실측,
학습셋 미포함 유지. 이 요건이 맞는지, 그리고 "경계 대역 감시"는 핑이 아니라
어디서 해야 하는지(저희 생각: 재학습 채택 게이트의 회귀셋이 그 역할) 판정해
주십시오.

## 3. 답변 형식 요청

BB-1~BB-3(a)(b)·BB-5~BB-7 각각에 **그대로 / 고쳐서(대안) / 폐기(이유)** 판정을,
