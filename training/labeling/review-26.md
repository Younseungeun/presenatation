# 26차 검토 요청 — 저희 벤치 제외 논리가 기각됐습니다. 그 잔해에서 나온 안건 일곱

## 0. "먼저 재야 할 것" 실측 — 여러분의 기각 조건이 그대로 발동했습니다

### 실측 ① CARD_MISMATCH 순수성 — 하네스 부작용 가설(저희 것) 기각

오탐 3건을 카드 형식 셋으로 라이브 r5에 재투입:

| 문장 | A 정상카드(UP) | B 카드 줄 제거 | C 빈 카드 |
|---|---|---|---|
| "현금흐름위험회피로 지정되어…" | 0.800 | 0.799 | 0.801 |
| "당사는 관련 공사에 대해 신뢰성…" | 0.748 | 0.762 | 0.760 |
| "현금 창출단위에 대하여 결정된…" | 0.730 | 0.694 | 0.737 |

**카드를 빼도, 비워도 점수가 움직이지 않습니다.** 모델은 카드를 읽고 모순을
판정한 것이 아닙니다. 여러분이 지정한 기각 조건("카드 제거에도 >0.7이면 지능의
문제") 충족 — **벤치에서 CARD_MISMATCH를 제외하려던 저희 안을 철회하고, 오탐
7건을 고스란히 떠안습니다.** DART 게이트는 v2 필터·N_clean 1,945·기준 3건
그대로, 채점 제외 없음.

### 실측 ② (자발) 그럼 이 헤드는 진짜 모순을 잡긴 하는가 — 잡습니다

여러분의 BB-3(b) 반증 조건을 뒤집어 실행했습니다. 홀드아웃의 진짜 카드 모순
5문항(상승 카드 + 하락 논지 본문) 투입 → **5/5 탐지 (0.761~0.861)**. 병명
확정: 헤드 사멸도, 하네스 부작용도 아닌 **과잉 일반화** — 진짜 모순을 잡는
능력은 온전한 채, 낯설고 어려운 공시체 산문까지 "카드와 무관한 글"로
뭉뚱그립니다. 처방은 CC-2.

### 실측 ③ (자발) 안 잰 라벨 마저 — 최약 라벨은 따로 있었습니다

신규 위반 문장 4건씩 실투 (전부 학습셋 미포함):

- **RISK_INDUCEMENT**: 0.775 / 0.795 / 0.653 / 0.799 — 3/4 탐지, 경미한 둔화
- **UNSUPPORTED_CLAIM**: 0.106 / 0.435 / 0.795 / 0.638 — **1/4 탐지.** "외국인
  수급이 확인해 줬다"형 권위 차용은 0.106 바닥. 실측 전체에서 가장 무딘 라벨

### 실측 ④ (자발) 정상 핑 요건 ≤0.15 — 저희 요건이 자체 반증됨

흠잡을 데 없는 정상 자문 문장 2건("분할 매수로 접근하되 손절 기준을…" /
"시장 예상치에 부합…보수적 접근을 권합니다")의 전 라벨 최대값이 **0.242 /
0.231**. 진짜 정상 산문도 0.15 밑으로는 안 내려갑니다. 25차에 저희가 제안한
"정상 핑 ≤0.15" 요건은 현실 분포와 안 맞습니다 — 수정안은 CC-4.

**고정 제약 (갱신 1건 제안)**: λ=4 · 운영 경로 외부 API 0회 · KoELECTRA-small
14M · 512토큰 · 운영자 1~2인 · 즉시 거절 코드 원천만 · 학습 금지 목록에 **DART
정제판 1,945 추가 명문화** — 게이트로 승격된 순간 당연 귀결인데 목록에 명시가
없었습니다 (기존: 채점지 69·시드 17·홀드아웃 101·회귀셋·핑 문장)

**판정 불요 이행 목록** (25차 확정분, 순서대로 착수): 면제 구문 코드 원천 전용 +
등재 시 전수 재측정 · 연락처 정규식 날짜 lookahead · training/ledger.jsonl
(retroactive 표기) · 트립와이어 2연속 단축 · 8문항 핑(마진 요건은 CC-4 판정 후)

**보고 하나 — BB-6의 반증 조건은 이미 발동돼 있었습니다.** "현행 설정으로 당시
데이터를 재학습했을 때 성능이 확연히 떨어지면 빈칸에 비밀이 있었던 것" — 이
실험은 소실 사고 당시 이미 수행됐습니다: 같은 데이터의 재현 런이 회귀 6건
오답으로 소실 원본보다 확연히 나빴습니다(23차 부록 3). 즉 소실 원본의 대장
빈칸에는 실제로 성능의 비밀(다른 학습 설정)이 들어 있었고, retroactive 빈칸이
"여기 비밀이 묻혔다"는 표지로 기능한다는 여러분의 논리는 저희 이력에서 이미
실증된 상태입니다.

## 1. 검토 질문

#### CC-1. 기준 초과 상태의 라이브 r5 — 소급 퇴출은 아니라고 봅니다

제외 철회로 r5의 DART 실측은 7건, 새 기준은 3건 — **현행 라이브 모델이 새
게이트를 못 넘는 상태가 됐습니다.** 저희 안: **게이트는 채택 관문이지 소급 퇴출
장치가 아닙니다.** r5는 채택 당시의 게이트를 전부 통과했고, 새 기준의 소급
적용은 "기준을 조일 때마다 라이브가 비는" 구조를 만듭니다. 학생은 WARN만 하므로
초과분의 운영 비용은 산문 1,945건당 소견 4건 — 운영자가 흡수 가능한 크기입니다.
r5는 유지하고, 기준 3건은 **다음 채택부터** 적용합니다.

**질문**: 소급 비적용이 맞습니까? 아니면 "기준 초과를 알면서 운영"이 다른
종류의 부채입니까 — 판정과 함께, 이 판단이 틀렸다면 무엇이 관측될지(반증
조건)를 적어 주십시오.

#### CC-2. CARD_MISMATCH 과잉 일반화 — 대비쌍 처방과 재료의 출처 제약

병명이 과잉 일반화이므로 처방은 경계 선명화 대비쌍입니다: **정상 측 = 공시체
회계 산문**(방향 주장 없는 어려운 글, 라벨 없음) / **위반 측 = 진짜 카드
모순**(상승 카드 + 하락 논지). 단 재료 제약 하나 — **DART 문장 자체는 이제
게이트라 학습에 못 씁니다.** 교사 세션에 "공시 서식 풍의 회계·감사보고서체
문장을 새로 지어라"로 지시해 문체만 빌리고 문장은 새로 만듭니다.

**질문**: 문체 모사가 벤치 오염(Y-4형의 우회 — 게이트 문장을 안 베끼되 게이트
분포를 베낌)에 해당합니까, 아니면 "시험 범위를 알고 공부하는 것"으로
정당합니까? 경계 기준을 함께 판정해 주십시오.

#### CC-3. 다음 학습 배분 최종안 — 실측 ③이 배분을 다시 바꿨습니다

25차 배분안에서 두 가지가 갱신됩니다: UNSUPPORTED_CLAIM(실측 최약, 1/4)이
예방 몫이 아니라 주력 몫으로 승격, CARD_MISMATCH 30쌍 신설(CC-2). 최종안,
총 190건:

- 부정 구역 하드마진 40쌍 (정상-위반 단어 1~2개 차이)
- PRIVATE_INFO 경계 선명화 30쌍 (전언·간접 화법: 0.62~0.69 대역 표적)
- SOLICIT_CONTACT 외부 유도 30쌍 (블로그·카페·이웃신청)
- **UNSUPPORTED_CLAIM 경계 선명화 30쌍** (권위 차용형 필수 포함: "기관이/외국인이/
  리포트가 확인해 줬다" — 실측 0.106짜리 구멍)
- **CARD_MISMATCH 대비쌍 30쌍** (CC-2 규격)
- RISK_INDUCEMENT 하드마진 20쌍 (실측 0.653 대역 보강)
- 부사 지름길 검사: 채택 전, 부사 제거 동의어 재투로 0.4 미만 추락 여부 확인

**질문**: 이 배분의 판정과 — 한 라운드 190건이 "한 번에 너무 많은 라벨을
건드려 시소 간섭(BB-1)을 스스로 유발"하는 크기인지의 판단을 함께 주십시오.
(대안이라면: 2회 분할 — 1차 하드마진·PRIVATE_INFO·SOLICIT 100, 2차
UNSUPPORTED·CARD_MISMATCH·RISK 90)

#### CC-4. 정상 핑 마진 요건 — ≤0.15를 ≤0.30으로 완화합니다

실측 ④가 저희 요건을 반증했으므로 수정: **위반 핑 ≥0.85 / 정상 핑 ≤0.30,
채택 시마다 재실측.** 발작 감지(여러분의 gap 17 — 상수 출력)에는 위반·정상
격차 0.55면 충분하고, 0.30은 정상 산문의 실측 상단(0.24)에 여유를 둔 값입니다.

**질문**: 0.30이 맞습니까? 그리고 발작의 판정식을 "정상 핑 중 1건이라도
>0.30이면 밸브"로 할지, "위반·정상 핑 평균 격차 <0.4면 밸브"로 할지 —
전자는 단순하고 후자는 부분 발작(일부 라벨만 상수화)도 잡습니다.

#### CC-5. 트립와이어의 나머지 반쪽 — 시소 간섭의 판정식과 부검 절차

"이종 sha 2연속" 단축은 수용했습니다. 남은 것 둘:

**(a) 시소 간섭의 판정식.** "특정 라벨을 올렸더니 다른 라벨이 즉각 추락"을
기계가 읽을 수 있게: **같은 채택 판정에서, 신규 자료가 겨냥한 라벨의 회귀
문항은 전건 통과하면서 겨냥하지 않은 라벨의 회귀 문항이 2건 이상 새로 떨어지는
일이 — 서로 다른 sha에서 2회** 관측되면 발동. 이 정의가 너무 좁은지(1회로
충분한지) 판정해 주십시오.

**(b) 100M 부검 런의 절차화.** 여러분의 반증 조건(더 큰 체급에 같은 데이터 →
여유 통과면 용량 한계 입증)을 트립와이어 발동 시의 **1회성 진단 절차**로
공식화합니다: KoELECTRA-base(110M)를 같은 데이터·같은 설정으로 로컬 학습,
게이트만 돌리고 **채택하지 않음**(채택하면 그게 곧 체급 교체 — 별도 결정).
base 통과 = 용량 한계 확정 → 체급 교체 논의 개시 / base도 실패 = 데이터
품질(라벨 노이즈) 의심 → 신규 자료 재심. 이 감별식이 맞습니까?

#### CC-6. 어텐션 반증 조건의 프록시 — 점수 대역 추적

BB-3(a)의 반증 조건(어텐션 검사)은 저희 사이드카가 ONNX 추론 전용이라 실행
불가합니다. 프록시 제안: **표 조각 4건의 점수 대역 추적.** 다음 채택 모델에서
이 4건이 —

- **0.10~0.65 대역**으로 내려오면: 보되 억누름 — 강건함을 배운 것 (합격)
- **0.05 미만 바닥**이면: 토큰 소실 의심 — 토큰 수를 현행과 비교해 전처리
  결함 감별 (여러분 함정의 "우연히 공백 치환" 시나리오)

**질문**: 이 프록시가 어텐션 검사를 대신할 수 있습니까? 0.05·0.65 경계값의
근거가 약하다면 무엇으로 정해야 합니까?

#### CC-7. 면제 구문의 라벨 노이즈 갈림길 — 거부 리포트에 재심 동선을 답니다

BB-2의 gap 17(등재 거부가 "면제가 위반을 덮음"인지 "코퍼스 라벨이 원래
틀림"인지) 처방: 등재 거부 시 **하락 문항 전문을 거부 리포트에 노출**하고,
운영자(저희)가 라벨 재심 → 라벨이 틀렸으면 **채점지 정오표 절차** — 수정은
별도 대장(무엇을·왜·언제)에 기록하고, 수정 직후 현행 모델로 전 지표
재측정(수정이 성적을 바꾼 폭을 남김). 채점지의 학습 금지는 수정 후에도
그대로입니다.

**질문**: 채점지를 고칠 수 있는 문이 생기는 것 자체의 위험(측정 기준의
가소성)과, 틀린 라벨을 박제하는 위험 — 어느 쪽이 큽니까? 정오표에 상한(예:
연 N건)을 둬야 합니까?

## 3. 답변 형식 요청

**gap 17형 함정** 하나와 **반증 조건**을 함께. "먼저 재야 할 것"이 있으면 보유
데이터(채점지 69+시드 17 · 홀드아웃 101 · DART 정제판 1,945 · 창업자 배터리
31 · 대조군 54 · 라이브 사이드카 r5) 범위에서 지정해 주십시오 — 재고 나서
이행합니다.
