# 23차 검토 요청 — 학생이 출근했습니다. 이제 어떻게 키웁니까

## 0. 상황 — 처음으로 실측 기준선이 생겼습니다 (2026-08-21 밤)

사이드카를 실기동해 채택 하네스를 통과시키고 학생을 **라이브로 합류**시켰습니다.
이번 회차의 질문은 하나입니다: **이 실측 약점 지도를 보고, 무엇을 어떤 순서로
늘려야 합니까.**

채택 설정 (t=0.7, 최소최대 — 어떤 λ에서도 순이익 최대):

```
학생 단독: 문장 탐지 42.6% · 오탐 0.0% · 지연 p50 14.5ms
규칙+학생: 탐지 57.4% → 81.5% (새로 잡음 13건 · 새 오탐 0건 · 순이익 +13, λ=2·4·10 동일)
게이트: 순이익>0 ✓ · risk_heavy 0% ✓ · 즉시거절 오탐 0 ✓ · 시맨틱 핑 ✓
```

**유형별 약점 지도** (규칙 단독 / 학생 단독 / 합산):

| 유형 | 규칙 | 학생 | 합산 | 해석 |
|---|---|---|---|---|
| literal (직설) | 100% | 30.8% | 100% | 규칙이 완전 방어 — 학생 기여 0 |
| evasion (표기 회피) | 100% | 25.0% | 100% | 규칙이 완전 방어 — 학생 기여 0 |
| **paraphrase** | 4.2% | **58.3%** | 58.3% | **학생의 존재 이유. 아직 41.7%가 뚫린다** |
| **negation (부정 의미)** | — | **0%** | — | **완전 공백** — gap 17 겹침("손해 볼 일이 없습니다")을 학생 몫으로 넘겼는데(20차 X-3) 데이터가 0건이다 |
| 문서 축 (본문-카드 모순) | 0~37.5% | 0% | 0~37.5% | 구조적 공백 (512토큰·CARD_MISMATCH 영구 제외 — 8차 E-5) |

같은 날 시맨틱 핑 사건이 이 지도를 실물로 확인시켰습니다: "절대 손실이 나지
않습니다"(부정형 위반)를 채택선 통과 모델이 못 잡았습니다(PG 0.24). 부정 공백은
이론이 아니라 관측입니다.

**고정 제약**: λ=4 · 운영 경로 외부 API 0회 (합성 라벨은 대화 교사 수동 릴레이) ·
KoELECTRA-small 14M · 512토큰 · 운영자 1~2인 · 채점지(손코퍼스 86)·홀드아웃(합성 101)·
회귀셋은 어떤 경로로도 학습 금지 · 시맨틱 핑 문장 학습 금지

**가진 데이터**: 합성 학습 390 (v2, 라벨 8종) · 합성 홀드아웃 101 · 손코퍼스 86(채점지) ·
대조군 54 · 신조어 127 · 실 리포트 0 · 운영자 판정 0 · DART 미확보

## 1. 검토 질문

#### Z-1. 다음 합성 라운드의 예산 배분 — 약점 지도를 어떻게 읽습니까

합성 확장이 출시 전 유일한 성장 경로입니다(20차 X-4 확정). 위 지도에서 저희 독해:

- **literal·evasion 에는 한 건도 안 쓴다** — 규칙이 100%를 쥐고 있어 학생의 그 자리
  성적은 순이익에 0으로 계산된다. 학생이 거길 배우는 것은 보험(규칙 회귀 시 이중
  방어)인데, λ=4 아래에서 보험보다 공백 메우기가 급하다
- **부정 대비쌍이 1순위** — 0%이고, gap 17 겹침의 관할이 학생으로 명시돼 있으며,
  핑 사건이 실물을 보여줬다. "손해 볼 일이 없습니다"(위반) vs "약속드릴 수
  없습니다"(정상)류 대비쌍을 X-3 허용대로 합성한다
- **패러프레이즈가 2순위** — 58.3%의 남은 41.7%. 놓친 10건의 문장을 보면 완곡·간접
  화법("제가 책임진다는 말은 아끼지 않겠습니다")이 몰려 있다

이 배분이 맞습니까? 부정:패러프레이즈:기타 비율을 어떻게 잡습니까? 그리고 **재는 값
주의**: "유형별 탐지율"은 그 유형의 문항 수가 적으면(부정 표본 몇 건) 0%↔100%가
문항 하나로 뒤집힙니다 — 채점지의 부정 문항 자체가 지금 몇 건 없는데, 약점 지도의
해상도를 먼저 올려야 합니까?

#### Z-2. 규모와 수확 체감 — 390에서 얼마까지

- 14M 모델·라벨 8종에서 합성 데이터의 수확 체감이 어디쯤 옵니까? 390→800→1,500 중
  어디서 멈추고 재야 합니까?
- 교사가 대화 릴레이(수동)라 라벨 생산이 시간당 수십 건입니다. 대비쌍 합성은 한 쌍이
  두 문장이라 배로 비쌉니다 — 예산을 문장 수가 아니라 **교사 세션 수**로 잡아야
  합니까?
- 늘릴 때 홀드아웃도 20% 비율로 함께 늘립니까, 아니면 기존 101을 고정합니까?
  (늘리면 회차 간 비교가 끊기고, 고정하면 새 유형이 홀드아웃에 없다)

#### Z-3. 채점지 86의 해상도 — 학습셋이 커질수록 눈이 나빠집니다

학습 390→1,500이 되면 채점지 86이 못 보는 방향의 과적합을 못 잡습니다(20차 X-4에서
이미 지적). DART 3,000은 정상 문장만이라 오탐 축 전용입니다. **위반 쪽 채점지**를
늘리는 정직한 방법이 있습니까?

- 교사 라벨 합성을 채점지로 쓰는 것은 함정입니다 — 학습셋과 같은 생성 분포라
  "자기 시험 문제를 자기가 낸" 꼴이 됩니다
- 손으로 쓰는 것은 됩니다만 운영자 1~2인의 손은 유한합니다
- 운영 데이터가 유일한 탈출구라면, 출시 후 운영자 판정 몇 건부터 채점지 승격이
  가능합니까? (지금 accuracy 라벨 스키마가 그대로 검증셋이 된다는 설계는 있는데
  "몇 건부터 믿는다"의 기준이 없습니다)

#### Z-4. 첫 재학습의 망각 방어 — 회귀셋이 0건입니다

치명적 망각의 방어선(회귀 게이트)은 졸업 대비쌍에서 나오는데 **졸업이 아직 0건**이라
회귀셋이 비어 있습니다. 첫 재학습(합성 확장분 반영)의 후퇴 방어는 지금 둘뿐입니다:

- 채택 하네스 재통과 (같은 채점지 86 — 해상도 한계는 Z-3과 같음)
- 커버리지 라쳇 (유형별 합산이 이전 스냅숏보다 후퇴하면 채택 불가 — 오늘 기록함)

이걸로 충분합니까? 아니면 현행 모델이 잡은 문장들(놓친 것 말고 **잡은 것**)을
회귀 문항으로 박제해야 합니까 — 그건 채점지도 학습셋도 아닌 세 번째 격리 셋이
되는데, 그 문장들 자체가 채점지 출신이라 격리 원칙과 충돌합니까?

#### Z-5. 유형 빗나감의 처리 — 오늘 실측된 사례

끝까지 검증 중 실측: 패러프레이즈 수익 보장 문장("손실이 나면 제 돈으로
채워드릴게요")을 학생이 **잡긴 잡았는데 유형을 RISK_INDUCEMENT 로** 냈습니다.
위반 여부는 맞고 유형만 빗나감 — 하드 네거티브 정의(위반 여부 엇갈림만)에는 안
걸립니다. 그런데 학습 관점에서는:

- 이런 건을 운영자가 반려하며 PROFIT_GUARANTEE 로 지목하면 그 라벨이 학습에 들어가
  자연 교정됩니다 (기존 배선). 그걸로 충분합니까, 아니면 "위반은 맞는데 유형이
  빗나간 건"을 따로 세어야 합니까? 유형 정확도가 낮아도 보류는 되므로 소비자
  피해는 없는데, 운영자 화면의 소견 신뢰가 깎입니다 — 이건 성능 문제입니까
  표시 문제입니까?

#### Z-6. 시맨틱 핑과 학습의 경계 — 핑 오염

핑 실패 시 처방을 "직설 보장 유형을 보강하라(핑 문장 자체는 금지)"로 적어 뒀습니다.
그런데 "핑 인접 데이터 보강"이 반복되면 사실상 핑에 과적합한 모델이 됩니다 —
채점지 오염의 핑 판입니다. 핑 문장 금지만으로 충분합니까, 아니면 핑과 자카드/의미
거리 얼마 이내의 합성 문장을 금지해야 합니까? (형태 거리는 뜻을 못 재는 것이 이
스레드의 반복 교훈인데, 그럼 이 경계는 무엇으로 긋습니까)

#### Z-7. 문서 축 0%인 채 출시 — 순서 확인

본문-카드 모순은 구조적으로 이 모델 밖입니다(512토큰·NLI 필요 — 8차 E-5 영구 제외).
규칙의 방향 모순 37.5%가 전부인 채로 출시하고, NLI 교차 인코더는 운영 데이터가
쌓인 뒤의 과제로 미루는 순서가 맞습니까? 아니면 문장 축 성장(Z-1)보다 이쪽이
급합니까? — 판매 페이지에서 소비자를 실제로 낚는 것은 문장 위반보다 "본문은
얌전한데 카드가 자극적인" 쪽일 수 있습니다.

## 2. 답변 형식

1. **결론** — 한 문장
2. **각 항목 판정** — `그대로` / `고쳐서` / `버려라` + 대안
3. **근거** — λ=4 · 즉시 거절은 코드 원천만 · **운영 경로 외부 API 0회** 아래에서
4. **먼저 재야 할 것** — 지금 있는 것(위 데이터 목록 + 기동 중인 사이드카)으로
   잴 수 있는 것을 반드시. 사이드카가 살아 있으니 이번엔 추론 실험도 가능합니다
5. **반증 조건** — 항목마다, 그리고 **재는 값이 위반과 정상에서(또는 서로 다른
   원인에서) 같은 값을 낼 수 있는지**(gap 17형 함정)를 명시

### 반증 이력 — 이번 답변도 같은 운명일 수 있습니다

| 회차 | 반증된 가정 | 어떻게 |
|---|---|---|
| 17차 | "띄어 쓴 신조어 무사 = 안전" | 붙여 쓰면 12/25 오탐 |
| 18차 | "수동 2차 = 자동 2차의 느린 판본" | 여섯이 조용히 빠짐 |
| 19차 | "STRONG 확장은 오탐만 줄인다" | 주입 공격이 통과 |
| 20차 | 19차 W-4 "창 = 최대값+1" | 위반·정상이 gap 17 같은 좌표 |
| 21차 | "시험 1,500건 초록 = 검수 경로 건강" | 시험 환경이 몇 달째 장애 구성 |
| 22차 | "긴 문장은 복붙 후 낱말 하나로 자카드 통과" | 실측 min 0.851 — 방향이 반대 |
| 22차 | 21차 Y-6 "위반 문장에서 잦은 표현 = 등록될 표현" | 잦았던 것은 종결어미였다 |
| **23차 직전** | **22차 Y-1(b)의 이면 — "교과서적 위반은 어떤 모델도 잡는다"** | **채택선 통과 모델이 핑 문장에 침묵(PG 0.24) — 문장에 부정형이 섞여 있었고, 모델의 난이도 지형은 사람의 감과 다르다** |

특히 마지막 반증이 이번 회차의 주제 그 자체입니다 — **사람의 "쉬움/어려움" 감각으로
학습 예산을 배분하면 틀립니다.** Z-1의 배분 답도 감이 아니라 측정에서 나와야 하고,
그 측정의 gap 17형 함정까지 함께 밝혀 주십시오.

| **Z-2** 총량 동결·홀드아웃 고정 | 버려라(증량) | 수용 — 3라운드는 80문장만(총 ~470), 홀드아웃 101 고정, 전량 학습행 |

| **Z-4** 손코퍼스 20% 회귀 분리 | 고쳐서 | **완료.** 학생 단독(t=0.7)이 여유로 맞히는 17건(위반 10 ≥0.81 · 정상 7 ≤0.15)을 측정 선정 → `regressionSeed` 영구 격리, 채점은 SCORING_CORPUS(69), 회귀 게이트가 시드 17 + 졸업 대비쌍(DB)을 전 건 검사. 재실행: 게이트 전부 통과, 라쳇 재기준(사유 기록). 새 기준선: t=0.7 새오탐 0 · 순이익 +6 · 패러프레이즈 37.5% — 쉬운 문항이 빠져 숫자가 정직하게 줄었다 |
| **Z-5** 유형 빗나감 | 그대로 | 무변경 (보류가 1차 목표 달성 — 운영자 지목이 자연 교정) |
| **Z-6** 핑 이웃 드랍 | 고쳐서 | **완료.** `npm run check:ping` — 학습 후보가 핑과 자카드 ≥0.4면 드랍(22차 컷 재활용). 학습 절차(§2)에 상시 관문으로 편입 |
| **Z-7** 문서 축 미룸 | 그대로 | 수용 — NLI 교차 인코더는 운영 데이터 후 과제로 유지 |

### 실측 ① 부정어 지름길 검사 (probe:negation-shortcut) — **전제 반증**

부정어 포함 문항 26건(정상 12·위반 14)을 학생 단독으로 잰 결과:

```
부정형 정상: 평균 최고점 0.39 (min 0.15 · max 0.58)   ← 바닥(≈0)이 아니다
부정형 위반: 평균 최고점 0.64 (min 0.31 · max 0.85)
```

지름길 가설("부정어=무조건 통과를 외웠다")이 참이면 정상 점수가 바닥에 붙어야
