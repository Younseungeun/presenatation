# 35차 검토 요청 (사건 구동 — 창업자 지시 "110M 학습·최적화 진행") — 출시 준비 트랙 사전 등록 4건

## 0. 사건과 전제

창업자 지시: 110M(P1-A)의 학습과 최적화를 진행하라. 먼저 **배울 자료의 현황**을 그대로
적습니다 — 지금 학습이 제한적인 이유가 여기 있습니다:

| 자료 | 상태 | 110M 에 넣을 수 있나 |
|---|---|---|
| P1 (합성 727 + r8 180) | 이미 학습됨 (P1-A 가 그 결과) | 소진 |
| r6 264 (하드마진) | 격리 | **불가** — ① 유일한 zero-shot 잣대(넣으면 비교 축 소멸) ② P2 실측: 넣으면 110M 도 용량 경보 |
| 운영 데이터 | 출시 전이라 0건 | 출시 후 (LL-3) |
| 채점지·홀드아웃 101·핑 8·DART 1,945 | 영구 금지 | 불변 |
| 신규 합성 | 29차 FF-5 "합성 훈련 종료" 선언 | **판정 필요** (LL-1) |

즉 **지금 정당하게 넣을 새 자료는 없습니다.** 남은 학습 경로는 ① 표적 소량 합성(재개
판정 필요) ② 출시 후 운영 데이터(절차 예약)이고, 최적화 경로는 ③ 정적 양자화 실험
④ 융합본 게이트 조기 완료(이미 실행 — 결과 아래)입니다. 넷을 안건으로 올립니다.

## LL-1. SOLICIT 표적 보강 라운드 (r9 소량) — 합성 재개 판정

- **배경**: P1-A 의 유일한 하락 과목 — SOLICIT zero-shot 66→50%(r5 대비). 가설:
  P1 추가분(r8)이 UNSUPPORTED·CM 겨냥이라 SOLICIT 헤드가 간섭으로 밀렸다.
- **제안**: 소량 40~60쌍 (SOLICIT 위반 + 부정형 뜻 짝) 을 기존 릴레이 경로(운영자가
  Claude 대화에 브리프를 손으로 붙여넣는 교사 경로 — 운영 경로 외부 AI 호출 0 불변)로
  생성, **P1 + r9** 로 110M 재학습(r5 설정 — 설정 탐색이 아니라 자료 축), 게이트 전수 +
  r6 zero-shot. 접수 관문은 r6~r8 때 규칙 그대로: 쌍 자카드 ≥0.6 드랍, 핑·r6 오염
  검사(자카드 ≥0.4 드랍 — r9 가 r6 와 닮으면 zero-shot 잣대가 오염된다).
- **판정 요청**: FF-5 "합성 훈련 종료"는 14M 시대의 결론입니다(근거가 r6·r7 자료 결함 +
  **r8 의 14M 포화**였는데, 그 r8 을 110M 은 탈락 없이 담았습니다). 이 선언이 110M 에
  소급되는지 — 소급 안 되면 r9 소량 재개를 승인해 주십시오.
- gap 17 함정: "SOLICIT 을 고치러 갔다가 라운드가 커지는 것" — 40~60쌍 1회로 한정,
  결과 보고 추가 라운드를 여는 것은 별도 안건.
- 반증 조건: r9 학습 후 SOLICIT 이 올라도 ① 비겨냥 새 탈락 >2 ② 다른 과목 하락
  ③ 오탐 증가 — 하나라도 나오면 라운드 폐기, P1-A 유지 (r6 사고의 교훈: 하드마진
  소량도 그릇을 넘칠 수 있다).

## LL-2. 정적 양자화(static int8) 실험 — 449MB·지연 부담 절감

- **배경**: 동적 양자화는 4연속 자동 폐기(검증 오차 1.12~3.80). 그런데 동적과 정적은
  다른 기법입니다 — 동적은 활성값 범위를 실행 중 추정하고, 정적은 **보정 자료로 미리
  잽니다**(P1 표본 100~200건을 통과시켜 각 층의 값 범위를 굽는 방식). 110M 처럼 층이
  깊은 모델은 동적이 깨져도 정적이 사는 경우가 실제로 있습니다.
- **기대**: 449 → ~115MB(호스팅 메모리 부담 1/4), CPU 추론 가속 가능성. 실패해도
  얻는 것이 있습니다 — "110M 은 fp32 전제"가 기법 하나가 아니라 둘에 대해 확정됩니다.
- **절차**: int8 규칙 그대로 — 별도 후보·별도 지문·카나리아 재굽기·게이트 전수 재통과.
  자동 폐기 기준 동일(검증 오차 ≥ 0.5). QAT(학습 중 양자화)는 재학습이라 이번 범위 밖.
- 반증 조건: 정적도 오차 ≥0.5 또는 게이트에서 이진 판정 뒤집힘 — 양자화 트랙 최종
  종료, fp32 융합본 확정.

## LL-3. 출시 후 운영 데이터 재학습 — 절차를 지금 사전 등록

운영 50건은 110M 의 실전 검증셋(FF-4)이자 유일한 미래 학습 재료입니다. **같은 50건을
검증에도 학습에도 쓰면 자기 채점**이 되므로 분할 규칙을 미리 박습니다:

- **첫 50건 = 검증 전용 영구 동결** — P1-A(및 이후 모든 후보)의 실전 zero-shot 잣대.
  SOLICIT 재측정(33차 JJ-4)도 여기서.
- **51건째부터 = 학습 후보 적립** — 운영자 판정 규칙 그대로(오탐 → 하드 네거티브,
  미탐 → 지목 유형만, 경미·유형 미지목 제외). 100건쯤 쌓이면 "P1 + 운영분" 재학습을
  새 안건으로 올린다 (게이트 전수 + r6 + 동결 50).
- 판정 요청: 이 분할 규칙(50 동결 / 이후 학습)을 확정해 주십시오 — 출시 뒤에 정하면
  그때의 성적을 보고 정하게 됩니다(Y-4).

## LL-4. 융합본 게이트 전수 — 조기 실행 결과 (추인)
