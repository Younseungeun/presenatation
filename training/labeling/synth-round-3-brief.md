# 합성 3라운드 지시문 — 부정 대비쌍 40쌍 (교사 세션용)

> 사용법: 아래 "═══ 교사에게 붙여넣을 부분 ═══"을 대화 교사(클로드 새 대화)에 그대로
> 붙여넣고, 받은 JSONL을 파일로 저장한 뒤 §2의 명령을 순서대로 실행하세요.
> 예상 소요: 교사 세션 1회.

## 왜 이 구성인가 (23차 검토 + 실측)

- 23차 판정: 합성 총량은 더 늘리지 않는다(Z-2 — 390에서 수확 체감). 이번 라운드는
  **부정 구역만** 겨눈 소량 정밀 사격이다 (40쌍 = 80문장, 총 470으로 억제)
- 검토 처방은 "부정형 **정상**만 합성"이었으나 **실측으로 수정**했다
  (probe:negation-shortcut): 모델은 부정어=통과 지름길을 외운 게 아니라(정상 평균
  0.39 — 바닥이 아님), 부정 구역에서 위반(0.64)과 정상(0.39)의 **분리가 임계값 0.7
  아래에 눌려** 있다. 정상만 넣으면 구역 전체가 내려가 위반 미탐이 악화된다 —
  경계를 가르치는 것은 짝이므로 **대비쌍**으로 간다 (20차 X-3 허용과 정합)
- 홀드아웃 101은 고정(Z-2) — 이번 산출물은 전량 학습으로 간다

당신은 한국 주식 리서치 플랫폼의 게시 전 검수 모델을 위한 학습 문장을 만듭니다.
이번 주제는 하나입니다: **부정 표현이 든 문장에서 "주장을 무르는 부정"과 "주장을
강화하는 부정"을 가르는 것.**

- 위반 예시(주장을 강화하는 부정): "이 자리는 손해 볼 일이 없습니다" — '없다'가
  보장을 말한다
- 정상 예시(주장을 무르는 부정): "수익을 약속드릴 수 없습니다" — '없다'가 약속을
  거둔다

**대비쌍 40쌍(80문장)**을 만들어 주세요. 한 쌍 = 비슷한 소재·비슷한 부정 어휘를 쓰되
한쪽은 위반, 한쪽은 정상. 배분:

- 수익 보장(PROFIT_GUARANTEE) 20쌍 — 손실 부재 단언, 보전 약속, 확정 수익
- 근거 없는 단정(UNSUPPORTED_CLAIM) 10쌍 — "틀릴 수가 없다"류 vs "단정할 수 없다"류
- 위험 조장(RISK_INDUCEMENT) 10쌍 — "망설일 이유가 없다, 다 실어라"류 vs "무리한
  진입은 권하지 않는다"류

규칙:
1. 부정 어휘를 다양하게: 없/않/못/아니/불가/제로/전무 — 쌍마다 같은 어휘를 양쪽에
2. 문체를 다양하게: 존댓말·해요체·명사형 종결을 섞고, 같은 문형을 반복하지 말 것
3. 실제 리포트 문장처럼 15~60자, 종목 실명 대신 "이 종목/해당 기업"
4. 출력은 JSONL — 한 줄에 하나, 정확히 이 형식:

{"text":"[카드] 방향 상승 / 목표 등락률 12% / 시한 60일 / 신뢰도 6/10\n[제목] \n[요약] \n[본문] (문장)","labels":["PROFIT_GUARANTEE"]}

- 정상 문장은 "labels":[] 
- [카드]의 목표·시한 숫자는 쌍마다 자연스럽게 바꿀 것 (5~30% / 7~180일)
- 코드펜스 없이 JSONL 원문만 출력

## §2. 받은 뒤 실행 순서

```
1. 받은 내용을 training/incoming-r3.jsonl 로 저장
2. npm run gen:ingest -- training/incoming-r3.jsonl --from conversation-<교사명>
     → 형식·라벨·채점지 유출·중복을 검증해 통과분만 generated.jsonl 에 들어감
3. npm run check:ping        ← 핑 오염 검사 (걸리면 해당 줄 삭제 후 재실행)
4. 재학습:  training/ 에서
     python train.py --data data/synth.v2.jsonl data/generated.jsonl data/founder.jsonl
     python export_onnx.py
5. 사이드카 재기동 → npm run eval:student -- --sweep
     게이트: 순이익>0 · risk_heavy 0% · 거절오탐 0 · 시맨틱 핑 · **회귀 17건 전 건**
6. 효과 측정: npx tsx scripts/probeNegationShortcut.ts
     — 부정 구역 분리(정상 0.39 / 위반 0.64)가 벌어졌는지가 이 라운드의 성적표다
```

⚠ 금지: 교사에게 손코퍼스·대조군·회귀 시드 문장을 보여주지 말 것 (채점지 오염).
train:export 는 잠겨 있다 — 학습 원천은 합성·수기·운영자 판정뿐이다.
