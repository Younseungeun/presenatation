# 합성 9라운드 지시문 — SOLICIT 표적 보강 50쌍 (35차 LL-1 승인 · 110M 전용)

> 사용법은 지난번과 같습니다: 아래 경계 안을 새 클로드 대화에 붙여넣고, 받은
> JSONL을 저한테 그대로 전달(또는 training/incoming-r9.jsonl 로 저장) 후 "받았어".
> 나머지(접수 검증·쌍 자카드·핑/r6 오염 검사·110M 재학습·게이트 전수·채택 판단)는 제 몫입니다.

## 왜 이 구성인가 (35차 LL-1 — 1회성 표적 실험)

- **표적**: 110M P1-A 의 유일한 하락 과목 SOLICIT_CONTACT (zero-shot 66→50%).
  가설: P1 추가분(r8)이 UNSUPPORTED 겨냥이라 SOLICIT 헤드가 간섭으로 밀렸다
- **이 라운드로 한정** — 다른 과목 추가는 통제 변인을 깨는 사후 변형(검토자 명시)
- 학습 대상은 110M 뿐이다 (14M 은 FF-4 재봉인). 채택선: 전 게이트에서 r5 상회 +
  SOLICIT 복구, 반증: 비겨냥 탈락 >2 또는 다른 과목 하락 → 라운드 폐기, P1-A 유지
- ⚠ 받은 뒤 제가 r6 격리본과의 유사도 검사(자카드 ≥0.4 드랍)를 돌립니다 — zero-shot
  잣대가 오염되면 측정 자체가 죽기 때문. 드랍이 많으면 부족분만 다시 요청합니다

당신은 한국 주식 리서치 플랫폼의 게시 전 검수 모델을 위한 학습 문장을 만듭니다.
**대비쌍 50쌍(100문장), 전부 SOLICIT_CONTACT(플랫폼 밖 접촉·1:1 상담 유도) 과목** —
한 쌍 = 비슷한 소재·비슷한 핵심 어휘를 쓰되 한쪽은 위반, 한쪽은 정상.

**① 부정형 뜻 짝 하드마진 — 25쌍**
- 위반: "종목 상담은 개인적으로 연락 주시면 자세히 안내해 드립니다"
- 정상: "종목 상담은 개인적으로 연락 주셔도 안내해 드릴 수 없습니다"
- 같은 어간·같은 소재에서 **단어 1~2개(부정어·조동사)만 갈라** 위반↔정상이 되게.
  정상 쪽은 외부 접촉 거절·1:1 상담 불가 고지·"문의는 플랫폼 안에서만" 안내
- ⚠ 부정어를 정상 쪽에만 몰지 마십시오 — 위반 문장에도 무해한 부정("놓치지 마세요"류)을
  섞어, 모델이 "부정어 = 정상"을 지름길로 외우지 못하게

**② 이름 없는 외부 유도 변형 — 15쌍**
- 위반: 채널 이름·번호 없이 행동으로 유도 — "프로필에 적힌 곳으로 오시면 됩니다",
  "제 필명을 검색하면 더 많은 자료가 있습니다", "쪽지 주시면 따로 정리해 드립니다",
  "이웃 추가하시면 비공개 글을 보실 수 있습니다"
- 정상 대비: 사칭 경고("제 이름으로 연락하는 계정은 전부 사칭입니다"), 플랫폼 안
  기능 안내("후속 분석은 이 플랫폼의 다음 리포트로 올립니다")
- ⚠ 채널 실명(텔레그램·카카오톡)·전화번호·표기 장난(글자 벌리기)은 쓰지 말 것 —
  그쪽은 규칙 엔진 담당이고, 여기서 겹치면 학습이 낭비됩니다

**③ 간접·완곡 유도 — 10쌍**
- 위반: 접촉 방법을 안 적고 의도만 흘리는 것 — "여기에 다 적을 수 없는 이야기가
  있습니다, 아시는 분은 아실 겁니다", "더 깊은 이야기는 다른 자리에서 나누겠습니다"
- 정상 대비: "본 리포트에 판단 근거를 모두 담았습니다", "추가 질문은 받지 않는 점
  양해 바랍니다"

규칙:
1. 문체 다양하게 (존댓말·해요체·명사형 종결), 같은 문형 반복 금지 — 쌍끼리도
   서로 닮지 않게 (납품 후 쌍 간 유사도 검사로 닮은 쌍은 드랍됩니다)
2. 15~60자, 종목 실명 대신 "이 종목/해당 기업"
3. 출력은 JSONL — 한 줄에 하나, 정확히 이 형식 (코드펜스 없이 원문만):

{"content":"(문장)","direction":"UP","magnitudePct":12,"horizonDays":60,"confidence":6,"labels":["SOLICIT_CONTACT"]}

- 정상 문장은 "labels":[] · 위반은 ["SOLICIT_CONTACT"]
- magnitudePct(5~30)·horizonDays(7~180)·confidence(4~9)는 쌍마다 자연스럽게 변화
- direction 은 대부분 "UP", 대여섯 쌍은 "DOWN"

## 받은 뒤 (제가 실행 — 35차 LL-1 등록 절차)

접수 검증(gen:ingest 형식) → 쌍 자카드 ≥0.6 드랍 → check:ping(8문항) →
**r6 격리본 오염 검사(자카드 ≥0.4 드랍 — 신설)** → checkSynthOverlap(DART 3-gram) →
**110M 재학습**(P1 + r9, r5 설정, GPU, 이름 IRIS.v6-P1R9) → export → 게이트 전수
(채점지 스윕·DART 켜진 라벨·시소 vs r5·핑·부사·희석·score-median·**zero-shot r6**) →
채택 판단: SOLICIT 복구 + 전 게이트 r5 상회 + 반증 조건(비겨냥 >2·타 과목 하락) 미실현.
통과 시 P1R9 가 P1-A 를 대신해 차기 후보(융합·게이트 재통과 포함), 실패 시 P1-A 유지.
