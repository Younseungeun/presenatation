# 아직 근거를 못 적은 숫자 상수 — **갚아야 할 빚의 명세**
#
# 규칙은 하나다: `src/`에서 내보내는 숫자 상수에는 `@근거 <시뮬|규칙|계약|설계> <이유>`가
# 붙어 있어야 한다. 못 붙인 것만 여기 이름을 올리고, 그 이름들만 시험을 통과한다.
#
#   · 새 상수를 쓰는 사람은 이 파일을 고치지 않는 한 반드시 근거를 적게 된다
#   · 기존 상수를 건드리는 사람은 이유를 찾아 적고 여기서 이름을 지우게 된다
#   · **줄 수가 곧 남은 빚의 양이다** — 늘어나면 시험이 실패한다
#
# 확인: `npm run debt:constants`  ·  시험: src/__tests__/constantBasis.test.ts
#
# ── 왜 이것들이 남았나 ────────────────────────────────────────────
# 대부분은 주석에 "초안 수치"라고 적혀 있는 값들이다. 즉 근거가 **없어서** 못 적는 것이지
# 적기 귀찮아서가 아니다. 이 목록의 진짜 쓸모는 여기에 있다 —
# **어떤 값이 한 번도 유도된 적 없는지**를 처음으로 한자리에 모아 놓은 것.
# 그 다음 순위도 여기서 나온다: 돈과 판정에 닿는 것부터 갚는다.
#
# ── 갚을 수 없는 이유가 따로 있는 것 ──────────────────────────────
# src/domain/instrumentRisk.ts:MIN_MARKET_CAP
#   재는 법은 안다 — 시총 구간별 '일일 등락 상위 1%'의 크기를 보고 꼬리가 비선형으로
#   두꺼워지는 절벽을 찾으면 된다(43차 검토). 못 재는 이유는 **데이터가 없어서**다:
#   Instrument.marketCap이 전 종목 null이고(scripts/calibrateStability.ts 실측),
#   업비트·KIS 목록 API가 시총을 주지 않는다. 즉 이 상수가 지키는 SMALL_CAP 규칙은
#   **지금 사실상 돌지 않는다** — 운영자가 손으로 채운 종목에서만 걸린다.
#   시총 원천(KRX 통계·CoinGecko 등)을 붙이는 것이 선행 조건이다.
#
