# 등급 임계값 — 수익성·지속 가능성 시뮬레이션 (2026-07-13)

> 실행: `npx tsx scripts/simulateTierThresholds.ts` (리서처 풀 20,000명, 시즌 점수 리셋 가정)
> 결론: **실버 600 / 골드 2,000 / 플래티넘 5,000 채택** (기존 초안 1,000/3,000/8,000에서 하향)

## 전제: 임계값은 마진이 아니라 공급·신호를 조절한다

선결제 할증 때문에 등급별 실효 수수료는 수렴한다:
브론즈 20%, 실버(선결제 10%) 19%, 골드(20%) 19%, 플래티넘(30%) 19%.
→ 임계값이 조절하는 것은 플랫폼 마진이 아니라
① **리서처 유지** (승급이 너무 멀면 콜드스타트 단계에서 공급 이탈)
② **등급의 신호 가치** (너무 가까우면 전원 상위 등급 = 구매자 변별력 상실)
③ **구독 상품 개시 시점** (플래티넘 해금 특권 — 2단계 안정 매출의 전제)

## 시뮬레이션 설정

- 공급자 풀: 승률 50~55% 20% / 60~67% 35% / 68~75% 30% / 76~83% 12% / 84~90% 3%
  (경력자 직접 영입 전제 — 완전 무실력 비중 낮음)
- 게시량 시즌 12~40장 (주 1~3장, 실력 있을수록 활동적), 신뢰도는 proper scoring 최적값
- 기본 점수 U(20,100), 시즌마다 점수 리셋 후 재산정

## 결과

| 후보 | 브론즈/실버/골드/플래티넘 분포 | 준수 리서처(승률 65~72%) 첫 시즌 실버 도달 | 실버+ 시즌 유지율 |
|---|---|---|---|
| 낮춤 600/2k/5k ✅ | 59% / 30% / 9% / **2.0%** | **50%** | 65% |
| 기존 초안 1k/3k/8k | 74% / 21% / 5% / 0.5% | 28% | 62% |
| 높임 1.5k/5k/12k | 83% / 15% / 2% / 0.1% | 12% | 55% |

## 채택 근거 (600/2,000/5,000)

1. **지속 가능성 — 공급 유지**: 준수한 리서처의 절반이 첫 시즌에 실버(선결제 10% 해금)를
   경험한다. 1~2시즌 안에 승급을 체감해야 콜드스타트 단계의 무보수 위험을 견딘다.
   기존 초안은 28%로, 4명 중 3명이 한 분기 내내 브론즈 → 이탈 리스크.
2. **신호 가치 — 피라미드 유지**: 실버 30%·골드 9%·플래티넘 2%는 "상위 등급 = 희소"라는
   변별력을 유지하는 분포. 낮췄는데도 플래티넘은 여전히 50명 중 1명 수준.
3. **수익성 — 구독 매출 개시**: 플래티넘 2%라야 초기 풀(30~50명)에서 구독 상품(플래티넘
   해금)이 실제로 열린다. 기존 초안(0.5%)은 1~2년 내 구독 매출 개시가 사실상 불가능.
4. 실효 수수료는 등급과 무관하게 ≈19~20%라 하향해도 마진 훼손 없음 (§전제).

## 남은 관찰 항목

- **강등 요요**: 실버+ 중 ~35%가 다음 시즌 브론즈로 강등 (실력이 아니라 분산 탓 포함).
  운영 데이터로 확인 후 필요 시 완충 장치 검토: 강등 유예 1시즌, 또는 직전 시즌
  점수의 일부 이월(예: 30%)
- 게시량 분포가 가정(12~40장)과 크게 다르면 재시뮬레이션 필요 — 점수는 물량×실력의
  함수이므로 실데이터 캘리브레이션 필수
- 챌린저는 상대평가(플래티넘 상위 5%)라 임계값 무관
