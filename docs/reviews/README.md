# 외부 검토 프롬프트 기록

회차마다 **외부 AI 검토자에게 보낸 요청문** 원본입니다. 28차부터 남깁니다
(그전 것은 로컬 임시 폴더에 있다가 사라졌습니다).

## 왜 저장소에 두나

지금까지 이 파일들은 로컬 임시 폴더에 있었고, **컴퓨터를 옮기거나 세션이 끝나면
사라졌습니다.** 그런데 이것들은 대화 기록이 아니라 **결정의 근거**입니다 —
"왜 보상 원장을 Settlement과 나눴나", "왜 문턱을 7에서 14로 올렸나"의 논증이
코드 주석보다 길고 자세하게 여기 있습니다. 코드 주석은 결론을 적고, 여기는
**받아들인 것과 반박한 것**을 함께 적습니다.

## 읽는 법

각 파일의 구조는 대체로 이렇습니다:

1. **앞 회차 답변에 대한 처리** — 채택 / 반박 / 더 밀고 간 것
2. **이번 회차에 구현한 것**과 그 근거
3. **스스로 찾은 결함** (검토자가 지적하지 않은 것)
4. **답을 듣고 싶은 것** — 다음 회차의 질문

반박한 대목이 특히 볼 값어치가 있습니다. 무엇을 왜 안 했는지가 남아 있는
유일한 자리입니다.

이 파일들은 **보낸 시점의 사실**을 담고 있습니다. 이후 회차에서 뒤집힌 것이 있습니다 —
가장 큰 것은 37차의 "7일 유지" 판단으로, 38차에서 측정 오류를 잡고 **14일로 바꿨습니다.**
