INTOVILL 시스템 지도

위 — 단계 흐름: 무엇이 언제 일어나는가 · 아래 — 분류도: 무엇이 존재하는가

① 단계 흐름

왼쪽 세로줄이 진행 단계, 오른쪽 가지가 그 단계에서 멈추거나 갈리는 자리.

단계 여기서 멈춘다 — 사람이 봐야 풀린다 자동으로 끝난다 (좋은 결과라는 뜻은 아님)

② 분류도

일곱 분류 — 돈이 지나가는 세 칸(상품·게시 / 판정 / 정산·돈), 그것이 기대는 두 칸(시세·데이터 / 점수·평판), 가로지르는 두 칸(구매자 보호 / 운영·감시).

화면(리더보드·MY 등)과 코드 밖 블로커(업권 판단·계약·약관)는 일부러 뺐다 — 전자는 시스템의 표면이고 후자는 시스템이 기다리는 것들이다. 현재 규칙의 정본은 언제나 코드와 CLAUDE.md. · 2026-08-16 기준, docs/system-map.html
