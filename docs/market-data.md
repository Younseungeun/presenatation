## 1. 자산군(Asset Class) 모델

예측 카드와 판정 엔진은 자산군 공통으로 동작하고, 자산군별 차이는
**시세 소스·거래일 규칙·티커 표기**의 세 가지로 격리한다.

| 자산군 | 코드 | 티커 표기 | 통화 | 거래일 기준 시간대 | 특성 |
|---|---|---|---|---|---|
| 국내주식 | `KR_EQUITY` | 6자리 단축코드 (예: `005930`) | KRW | Asia/Seoul | 거래정지·상폐 있음 |
| 해외주식(미국) | `US_EQUITY` | 심볼 (예: `AAPL`) | USD | America/New_York | 거래정지·상폐 있음, 서머타임 |
| 암호화폐 | `CRYPTO` | 업비트 마켓코드 (예: `KRW-BTC`) | KRW | Asia/Seoul (업비트 일봉 기준) | 24/7 거래, 휴장 없음, 거래소 상폐 있음 |

- **판정은 항상 해당 자산의 표시 통화 기준** — 목표가·기준가·판정가가 같은 통화이므로 환율 개입 없음
- **거래일 날짜는 자산군의 시간대로 환산** — 예: 미국주식 시한이 KST 새벽이면 ET 기준 전일 장 데이터로 판정
- 암호화폐는 24/7 거래라 "휴장일 직전 종가" 규칙이 사실상 발동하지 않음. 일봉 마감은
  업비트 KST 자정 기준으로 약관에 명시 (국내 사용자 기준 직관성 우선)
- 유럽·아시아 주식 등 추가 자산군은 이 표에 행을 더하는 방식으로 확장

## 2. 판정 엔진이 요구하는 데이터

`src/domain/judgment.ts`의 `judge()`는 순수 함수이며, 입력 `MarketSnapshot` 하나로 판정한다.
데이터 레이어의 책임은 **이 스냅샷을 자산군별로 정확하게 만들어내는 것**이 전부다.

| 필드 | 용도 | 원천 데이터 |
|---|---|---|
| `highSincePublish` | 상승 목표가 도달 판정 | 게시일~시한 일봉 고가의 최댓값 |
| `lowSincePublish` | 하락 목표가 도달 판정 | 게시일~시한 일봉 저가의 최솟값 |
| `priceAtDeadline` | 수익률형(RETURN_PCT) 판정 | 시한 당일(휴장 시 직전 거래일) 종가 |
| `status` | 판정 불가 처리 | 거래정지·상장폐지(거래소 상폐) 여부 |

추가 요구사항:
- **일봉 데이터로 충분** — 판정은 시한 도래 후 배치로 실행되므로 실시간 불필요
- **감사 가능성** — 판정에 사용한 원천 데이터를 스냅샷으로 저장해 분쟁 시 재현
  (`Judgment.marketSnapshotJson`)
- ~~액면분할·감자 등 기업행위 발생 종목은 판정 불가(AMBIGUOUS) 처리 후 수동 검토 (MVP 단순화)~~
  → **폐기 (2026-08-12).** 지금은 **앵커 방식**으로 자동 리베이스한다(`domain/corporateAction.ts`):
  게시 시점에 그날 종가를 적어 두고(`baseCloseAnchor`), 판정 때 같은 날짜를 다시 조회해
  달라진 배수가 곧 조정 배수다. 원주가 대조로 교차검증하고, **감지는 됐는데 반영하지
  못하면 판정 자체를 이월한다**(눈금이 어긋난 것을 알면서 채점하지 않는다)

## 3. 자산군별 데이터 소스

> **결정 (2026-08-10): KIS 하나가 국내·미국을 모두 담당한다.** 아래 후보 표는 그 결정에
> 이르기까지의 비교 기록이다 — ✅ 표시는 **지금 도는 것**을 뜻한다.
> 갈아탄 이유는 둘: ① 금융위 시세는 **D+1 지연**이라 결제 순간 차단(장중 보호)이
> 원천적으로 불가능했다 ② Twelve Data 무료는 분당 8회라 종목 24개를 도는 배치가
> **매번 다른 결과**를 냈다(초과분이 조용히 건너뛰어져 판매 마감이 무작위로 적용됐다).
> KIS는 국내 실시간 + 미국 0분 지연 실시간을 무료로 주고 초당 1회를 허용한다.

| 후보 | 비용 | 갱신 | 인증 | 비고 |
|---|---|---|---|---|
| **KIS Developers** ✅ 주 소스 | 무료 | 실시간 | 증권사 계좌 + APP Key | 2026-08-10 전환. 일봉은 1회 100건이라 120거래일은 2회 호출 |

**"완전 무료 + 상업 이용 + 안정성"을 다 만족하는 소스는 없다.** 단계별로 나눠 간다:

| 단계 | 소스 | 비용 | 비고 |
|---|---|---|---|
| **현재** | **KIS Developers** ✅ 주 소스 | 무료(계좌) | 2026-08-10 전환. 0분 지연 실시간, 초당 1회. 종목 상태(거래정지·상폐)는 **KIS 미국 마스터에 없어** 나스닥 공개 파일로 보완 |
| 개발·검증 폴백 | Stooq | 무료, 키 불필요 | EOD CSV. **키가 없을 때 개발 모드에서만** 폴백 — 프로덕션은 절대 폴백하지 않는다 |
| 교차검증 두 번째 소스 | Alpaca 또는 Twelve Data | 무료(계좌) / $29월~ | **미착수** — 판정 교차검증(domain/crossCheck.ts)에 미국 소스가 아직 없다 |

  리포트에 기준 거래소 표기

## 4. 판정 배치 흐름

```
자산군별 배치 스케줄 (2026-08-12 확정 — 크론이 아니라 **프로세스 하나의 순차 큐**,
npm run scheduler. KIS 토큰 발급이 분당 1회라 배치를 따로 걸면 같은 분에 겹쳐 실패한다):
- KR_EQUITY: **마감 +5분 = 15:35 KST** (창구 1시간 — 잠깐 죽어도 그날 판정을 놓치지 않는다)
- US_EQUITY: **마감 +5분 = 16:05 ET**
- CRYPTO:    **09:05 KST 고정** (마감이 없다)
- 기동 직후 **따라잡기**: 시작할 때 시장을 가리지 않고 한 번 돌려 밀린 것을 정리한다
  (판정은 멱등이라 중복 실행이 안전하다)

공통 파이프라인 (runJudgment):
1. 시한이 지났고 미판정인 PredictionCard 조회 (자산군 필터)
2. 카드별:
   a. registry에서 자산군의 provider 선택
   b. provider.getDailyQuotes(ticker, publishedAt, deadline)  ← 자산군 시간대로 날짜 환산
   c. provider.getSecurityStatus(ticker, deadline)
   d. buildMarketSnapshot() → judge() → 판정 결과
   e. 판정 성공 → Judgment 저장 (원천 스냅샷 JSON + 소스 식별자)
                → 해당 리포트의 모든 에스크로 Purchase에 settle() 적용
   f. 데이터 미도달/결측 → 다음 배치로 이월 (백오프, 마지막 눈금은 하루)
3. **시한 후 7일** 이월되면 운영자 보류 큐로 (수동 판정, 사유 기록 필수)
4. **시한 후 14일**에 시스템이 판정 불가·전액 환불로 닫는다 (JUDGMENT_HARD_CAP_DAYS).
   자동 회복 유예 중이어도 **16일은 못 넘는다**(JUDGMENT_ABSOLUTE_CAP_DAYS) —
   에스크로 정산 시한 약속이 자동 회복의 권한보다 위에 있다
```

- **멱등성**: `Judgment.predictionCardId` unique — 재실행해도 중복 판정 불가
- **레이트 리밋**: KIS 초당 1회(계정 합산) → 한 회차 `JUDGE_BATCH_SIZE`장으로 끊고
  커서로 앞으로 나아간다. 같은 종목 카드가 여럿이면 시세 호출은 1회(memoizeRegistry).
  장중 감시 갱신은 회차당 60종목이 상한(1.1초 × 60 = 66초, 2분 주기에 맞춘 값)
- 자동 추정이 애매하면 항상 **판정 불가(사람 확인) 쪽으로 기울인다** — 오판정 1건이
  평판 시스템 전체 신뢰를 훼손

## 6. 엣지 케이스 정리

| 케이스 | 처리 |
|---|---|
| 시한이 휴장일(주말·공휴일) | 직전 거래일 종가로 판정 (약관 명시). 크립토는 해당 없음 |
| 미국주식 시한의 시간대 해석 | 자산군 시간대(ET) 기준 날짜로 환산 후 판정 |
| 게시~시한 사이 거래정지 후 재개 | 거래된 날짜 데이터만으로 판정 |
| 시한 시점 거래정지 지속 | UNDECIDABLE(TRADING_HALT) → 전액 환불 |
| 상장폐지 / 거래소 거래지원 종료 | UNDECIDABLE(DELISTED) → 전액 환불 |
| 코인 하드포크·티커 변경·스왑 | UNDECIDABLE(AMBIGUOUS) → 수동 검토 (MVP) |
| 액면분할·감자 등 기업행위 | UNDECIDABLE(AMBIGUOUS) → 수동 검토 (MVP) |
| 데이터 소스 장애 | 판정 이월 (멱등 재실행), 5영업일 초과 시 보류 큐 |
| 게시일이 비거래일 | basePrice는 게시 시점 직전 거래일 종가로 고정 (게시 플로우에서 확정) |
| 업비트 미상장 코인 | MVP는 업비트 상장 코인만 허용 (게시 시 검증). 바이낸스 확장은 후순위 |

### 기준가 확정과 단기(단타) 예측

기준가(basePrice)가 EOD(직전 거래일 종가)면 초단기 예측은 조작 가능하다:
리서처가 당일 장이 이미 움직인 걸 보고 오후에 게시해도 기준가는 어제 종가라서,
실현된 등락을 "적중"으로 가로챌 수 있다. 그래서 **최소 검증 시한은 기준가 방식에 연동**된다.

| 자산군 · 게시 시점 | 기준가 확정 방식 | 최소 시한 |
|---|---|---|
| CRYPTO (상시) | 게시 순간 실시간 현재가 (업비트 ticker API) | **1일** |
| KR 주식 · **개장 전** (평일 08:00 KST 이전) | 직전 거래일 종가 — 판정 시 소급 확정 | **당일 종가** |

### 주식 단기 예측 컷오프 스킴

**KR 개장 전 게시 (당일 종가 예측 허용)** — "당일 체결 정보가 아직 없다"가 조작 방지의
근거. 월요일 개장 전 게시자가 가진 정보는 금요일 종가 + 공개 뉴스뿐.

- 컷오프 **08:00 KST**: 대체거래소 NXT 프리마켓(08:00~)과 KRX 장전 시간외(08:00~)가
  시작되어 가격 발견이 일어나는 시점. 국내주식은 전일 20:00(NXT 애프터마켓 마감)부터
  당일 08:00까지 실제 거래 공백이 존재하므로 이 창구가 성립한다
- 기준가(직전 거래일 종가)는 **게시 시점에 확정한다** (`PREV_CLOSE_AT_PUBLISH`, 2026-08-16).
  값 자체는 공개 정보라 신호 왜곡이 없다.
  · ~~데이터 D+1 지연으로 게시 시점엔 API에 없음 → 판정 배치가 소급 확정
    (`PREV_CLOSE_AT_JUDGMENT`)~~ → **폐기.** 그 전제는 금융위 시세일 때의 것이고,
    2026-08-10 KIS 전환으로 사라졌다(실측: KST 02:52에 직전 거래일 종가가 그대로 온다).
    미루는 동안 대가가 있었다 — 게시 관문이 기준가를 몰라 **크기 하한·방향 정합성을
    검증하지 못했고**(그래서 목표가형을 금지해야 했다), 판정 시 그 종가를 못 찾으면 이월됐다
  · **이때는 현재가를 묻지 않는다** — 장이 닫혀 있어 현재가 응답이 공급자 구현에 달려
    있고, 우리가 원하는 값은 하나로 정해져 있다(일봉의 마지막 종가)
  · 2026-08-16 이전에 게시돼 아직 판정 안 된 카드는 `PREV_CLOSE_AT_JUDGMENT`를 그대로
    유지하고, 판정 파이프라인의 소급 확정 경로도 그 카드들을 위해 남아 있다

**US에 개장 전 창구가 없는 이유** — 미국주식은 애프터마켓(전일 16~20시 ET) →
오버나이트 ATS(20~04시 ET; 국내 증권사 '주간거래'로 접근, 한국 낮 시간에 해당) →
프리마켓(04~09:30 ET)이 사실상 연속이라 **정보 공백 시점이 존재하지 않는다**.
실적 반응은 대부분 애프터마켓에서, 한국 투자자의 관찰은 주간거래에서 일어나므로
어떤 시각을 컷오프로 잡아도 직전 세션 정보를 가로챌 수 있다 → 당일·익일 카드 불가.

**장 시작 후·주말·US 상시 게시 (게시일+2일부터)** — 기준가를 **게시 이후 첫 정규장
종가**로 잡으면 게시 시점까지 실현된 등락이 전부 기준가에 흡수되어 게시 시각과
무관하게 정보 이점이 없다 (`DAY_CLOSE_AT_JUDGMENT`).

- **정규장 마감 후 게시면 기준일을 다음 거래일로 굴린다** (KR 15:30 / US 16:00 기준):
  그날 종가는 이미 공개된 과거라, 그대로 쓰면 애프터마켓·시간외 정보를 가로챌 수 있음
- 판정 구간은 기준가 확정일 **다음 거래일부터** — 기준일의 고가·저가로 목표가 도달을
  판정하지 않는다 (게시 전에 본 등락일 수 있으므로)
- 당일·익일(+1일) 시한은 거부

**공통**
- 정산 타임라인 (KR 당일 카드): 월 08:00 전 게시 → 월 15:30 시한 → 화 13:30 배치에서
  판정 + 기준가 소급 확정 + 에스크로 정산
- 공휴일 게시는 휴장일 달력 없이 못 거른다 — 시세가 없으면 판정 이월 → 수동 보류 큐 →
  전액 환불이라 오판정 없음. 휴장일 달력 도입 시 게시 시점 차단으로 개선 (§7)
- 코인 판정가는 여전히 일봉 종가(§1). 분 단위 정밀 판정은 업비트 분봉으로 가능하나 후순위
