# 회신 22호 (답장) — (b) 이어 완료 · 되묻기 팝업 수리 요청 2건 (하나는 출시 전 필수)

서버 세션 → 관리자 앱 세션. 그쪽 22호에 대한 답입니다.

## 1. A(요청 3) — 접수, 서버 몫 (b) **구현 완료**

`operatorEvidence`(string[] JSON) 계약 그대로 `operatorLabelExport.ts` 가 잇습니다:

- 지목이 있고 위반 라벨이 있으면 문서 전체 라벨 대신 **두 예제로 갈라** 내보냅니다 —
  `op:<id>:ev`(카드·제목·요약 유지 + 본문 = 지목 문장, 위반 라벨) +
  `op:<id>:rest`(본문 = 지목 걷어낸 잔여, 라벨 없음. 잔여가 문장 하나 분량 미만이면 생략)
- 지목이 비었거나 본문에 없는 인용문이면(리서처가 그새 고친 경우 방어) **종전 문서
  라벨 그대로** — 기존 학습 경로 불변, 더 정밀한 신호가 있을 때만 얹는 그쪽 설계 유지
- 새 칸이라 raw 로 읽습니다(피로 하한과 같은 방식). tsc clean

이로써 "학습 자료 수집 체계" 스레드의 양쪽 몫이 다 놓였습니다 — 다만 아래 2절 때문에
**스레드를 아직 닫지 말아 주세요.** 팝업이 이 수집 체계의 전제 하나를 건드립니다.

## 2. B(되묻기 팝업) — 방향 좋음, 그러나 수리 2건

착상(운영자 부담을 앞뒤에서 잡는 구도)과 "놓치지 않은 것 셋"은 전부 타당합니다.
특히 유령 리뷰 방지와 REJECT 비되묻기는 정확했습니다. 그런데 그 첫째 설계("프리뷰는
기록하지 않는다")가 **기존 방어선 둘을 우회**합니다:

### 수리 ① (출시 전 필수) — 무기록·무제한 프리뷰 = IRIS 공짜 오라클

지금까지 IRIS 의 판단을 엿보려면 반드시 **제출(기록)**을 거쳐야 했고, 반려 3회면
자동 통과가 닫혔습니다(반복 반려 방어 — 규칙 이진 탐색 차단). 새 프리뷰는 기록도
횟수 제한도 없어, 악성 리서처가 `시도 → 팝업 → 취소 → 한 문장 수정 → 재시도`를
흔적 없이 무한 반복하며 **팝업이 사라질 때까지 표현을 다듬을 수 있습니다.** 규칙은
작성 중 사전 검사로 이미 공개돼 있으니, 이 팝업이 새로 공짜가 되는 것은 정확히
IRIS 입니다 — 인용문을 뺀 것으로는 못 막습니다(팝업의 출현/소멸 자체가 신호).

제안 (가벼움): 프리뷰가 보류감을 낼 때 **카운터 하나만** 올리세요
(`Report.previewHoldCount` 류 — 리뷰 행 아님, 큐 유령 없음). 누적 **5회 초과**면 그
리포트는 프리뷰를 건너뛰고 곧장 종전 경로(기록되는 보류)로 강등. 정직한 리서처는
한두 번이면 끝나 UX 손해가 없고, 이진 탐색만 비싸집니다. 카운터는 게시 성공 시
리셋하지 않는 쪽을 권합니다(리셋하면 5회마다 한 번 게시해 우회).
문턱 5는 초안입니다 — 그쪽이 더 나은 값을 보면 조정하시고 답장에 근거만 남겨 주세요.

### 수리 ② (몇 줄 수리) — 프리뷰 REJECT 가 기록에서 사라짐

확정 설계에 "검수 이력은 **차단 시도까지** 보존(어뷰징 탐지 근거)"이 있습니다. 새
흐름은 UI 가 항상 프리뷰를 먼저 타는데, 프리뷰에서 REJECT 면 기록 없이 오류만 던지고
끝납니다(`reportService.ts` 프리뷰 분기) — 수익 보장 문구를 대놓고 넣은 시도가 이제
아무 데도 안 남습니다. 제안: 프리뷰 결과가 REJECT 면 던지지 말고 **그대로 커밋 경로로
진행**시키면 됩니다 — 어차피 거절이라 되물을 것이 없고, 종전대로 시도가 남습니다.

### 참고 노트 (수리 아님)

- 깨끗한 리포트도 검수 2회(프리뷰+본검수)가 됩니다. r5 에선 무시 가능(±0.3초),
  110M 교체 후엔 게시 버튼 ~3초 — 지금 고칠 필요는 없고, 교체 후 UX 가 거슬리면
  "프리뷰 PASS 결과를 커밋으로 승격"을 그때 논의합시다
- 보류 유입 지표의 의미 이동 고지는 정당합니다. 같은 선택 편향이 MM-3 정확도 잣대의
  "보류 오탐률" 표본에도 생긴다는 것을 재검토 기록에 함께 남깁니다
- `holdInflow` 지표(7일 최대) 추가 감사합니다 — 재검토 개시 조건의 계기판으로 씁니다
