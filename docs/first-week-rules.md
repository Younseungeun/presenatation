# 출시 첫 주 — 절대 결정하면 안 되는 것 (운영자 행동 수칙)

> 2026-08-22 · 29차 FF-3 확정. 첫 주의 신호는 모델의 결함과 새 시스템에 대한 리서처의
> 적응통이 섞여 있어 **같은 모양**으로 온다. 그래서 첫 주에는 결정하지 않고 잰다.

| # | 하고 싶어질 것 | 판정 | 이유 · 최소 표본 |
|---|---|---|---|
| 1 | 오탐 신고 몰리는 유형의 임계값 상향 (t 0.7→0.8 등) | **금지** | 첫 주 오탐 신고는 반발 노이즈. **최소 1개월** 유지. 올렸더니 조용해진 것은 "안정"과 "미탐 폭증"이 같은 얼굴 |
| 2 | 창 분할 임계값 하향 (0.8→0.7) | **금지** | DART 오탐 폭발 (r6 실측 42건) |
| 3 | 첫 미탐 직후 그 문장 사전 등록 | **금지** | λ=4 방어선을 흔든다. 하드 네거티브 **50건**까지 수동 관리 — 미탐은 강제 철회로 처리하고 `operator.jsonl` 에 쌓는다 |
| 4 | 110M 부검 직후 출시 모델 교체 | **금지** | r5 라이브 데이터 **최소 2주** 관찰 뒤. `docs/model-swap-rule.md` |
| 5 | 피로 하한 3초 변경 | **조건부** | 첫 주 중앙값이 아니라 **승인 판정 시간의 하위 25% 분위(1Q)** 로 재조정. 시간이 기록된 승인 ≥ 50건일 때만. `MIN_DECISION_MS` (operatorLabelExport.ts) |

## 첫 주에 재는 것 (순서)

1. 판단 소요 시간 (유형별 중앙값 · 승인 중 시간 null 비율 — 0 이 아니면 큐 밖 승인 경로가 있다)
2. 오탐률 (운영자 승인 / 학생 소견)
3. 적립·게시 흐름
4. 뒤집힘율 (운영자 판정이 나중에 정정되는 비율)

## 반증 조건 (FF-3)

임계값을 건드리지 않고 **2주**를 버텼을 때 오탐 이의 제기 건수가 우하향하면 첫 주 폭증은
적응통이었다. 우하향하지 않으면 그때 1번을 안건으로 올린다 — 첫 주가 아니라.
