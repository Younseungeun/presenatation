# σ 추정기 — 캘리브레이션 (2026-08-13)

> 실행: `npm run calibrate:sigma` · 구현: `domain/stability.estimateDailySigma`
> 계기: 외부 AI 검토가 "과거 120거래일 변동성은 이벤트를 앞둔 압축 종목에서
> 체계적으로 과소평가된다"고 지적 → 실데이터로 확인됨.

## σ 하나가 세 곳의 원천이다

| 쓰임 | σ가 낮으면 |
|---|---|
| p₀ (무정보 도달 확률) | 낮아진다 → 적중 보상이 부풀려진다 |
| 예측 크기 하한 `1.2·σ·√T` | 낮아진다 → 쉬운 목표가 허용된다 |
| 안정성 별점 | 높아진다 → 실제보다 안전해 보인다 |

과소평가가 위험한 이유는 **구멍이 하나가 아니라 셋**이기 때문이다.

## 무엇을 쟀나

p₀에 필요한 것은 과거 σ가 아니라 **카드 기간 동안의** σ다. 그래서 물은 것은
"과거를 잘 요약하는가"가 아니라 **"앞으로의 실현 변동성을 얼마나 과소평가하는가"** 다.

- 종목 마스터에서 100종목 (국내 40 / 미국 40 / 코인 20). 레버리지·인버스·
  채권·우선주·SPAC 제외
- 각 종목 일봉 약 300거래일. 원점을 10거래일 간격으로 옮기며
  **과거로 σ 추정 → 이후 30 / 60 / 120거래일의 실현 σ와 비교**
- 관측 각 기한별 496개

### 1차 잣대(폐기)와 2차 잣대

1차에서는 "과소평가 비율"을 봤다. 그것은 **얼마나 자주** 틀리는지만 말할 뿐
**얼마나 이득인지**를 말하지 않는다. 외부 검토의 지적을 받아 두 축으로 바꿨다.

| 축 | 정의 |
|---|---|
| **불로 점수** | 실력 없는 사람이 σ 오차만으로 얻는 카드당 기대 점수. 채점은 σ_추정으로, 실제 결과는 σ_실제로 일어날 때의 기대값을 **크기·신뢰도에 대해 최대화**한 값. σ가 정확하면 반드시 0이다(적정 점수법) |
| **차단율** | σ 과대평가로 크기 하한이 정당한 값의 1.2배를 넘는 비율. 하한 ∝ σ라 곧 σ_추정/σ_실제 |

두 축은 상충한다 — 보수적일수록 불로↓ 차단↑. 파레토로 읽는다.

## 결과 — 현행 L120의 불로 점수는 0이 아니다

### 기한별 (전체, 관측 496개)

| 기한 | L120 불로 | >0 비율 | 중앙 비율 |
|---|---|---|---|
| 30거래일 | **14.6점/카드** | 46.6% | 0.955 |
| 60거래일 | **19.6점** | 57.5% | 0.833 |
| 120거래일 | **23.9점** | 60.7% | 0.796 |

카드당 14.6점은 시즌 20장이면 292점 — 하위 실력 코호트의 시즌 기대값(144점)보다
크고 시니어 임계값(1,330)의 22%다. **실력 없이 σ 오차만으로 얻는 값이다.**

**기한이 길수록 나빠진다.** 이는 외부 검토의 예상과 반대다 — 그쪽은 "장기 카드에는
단기 σ 반영을 감쇠하라"고 했으나, 실제로는 장기 forward σ가 과거 120일보다 높은
경향이라 장기일수록 보정이 더 필요하다. (다만 표본이 한 국면이라 단정하지 않는다)

### 추정기 비교 (기한 30거래일, 전체)

| 추정기 | 불로 점수 | >0 비율 | 차단 1.2× | 중앙 비율 |
|---|---|---|---|---|
| L120 (현행) | 14.6 | 46.6% | 33.3% | 0.955 |
| MAX(20,120) | 10.6 | 38.9% | 41.3% | 1.060 |
| **MAX(120,P10)** | **10.0** | 35.9% | 42.3% | 1.071 |
| MAX(20,120,P10) | 9.0 | 33.3% | 46.0% | 1.133 |
| EWMA λ=0.94 | 14.9 | 48.8% | 28.2% | 0.924 |
| 조화평균(20,120) | 16.2 | 48.8% | 26.6% | 0.921 |

EWMA와 조화평균은 **현행보다 나쁘다**. Parkinson이 단기 창(S20)보다 낫다.

### 가장 조용한 20% — 압축 후 분출이 사는 자리 (관측 99개)

| 추정기 | 불로 점수 | >0 비율 |
|---|---|---|
| L120 | 25.5 | 73.7% |
| MAX(20,120) | 20.3 | 64.6% |
| **MAX(120,P10)** | **18.5** | **51.5%** |

**Parkinson 하나가 S20보다 낫다.** 종가는 제자리인데 장중 폭이 벌어지는 국면을
종가 σ가 못 보기 때문이고, 외부 검토의 지적이 정확했다.

### 자산군이 갈린다 (기한 30거래일)

| 자산군 | L120 불로 | L120 중앙비율 | 진단 |
|---|---|---|---|
| 국내주식 (240) | **22.9** | 0.842 | 과소 — 보정 필요 |
| 미국주식 (196) | 6.8 | 1.057 | 이미 과대 |
| 코인 (60) | 6.8 | 1.125 | 이미 과대 |

## 채택

    σ = 코인이면 종가 σ(120거래일)
        아니면 max( 종가 σ(120거래일), Parkinson σ(10거래일) )

Parkinson: `σ_P = sqrt( mean(ln(H/L)²) / (4·ln2) )`. 고가·저가는 이미 받는 일봉에
들어 있어 **추가 API 호출이 없다.**

| 자산군 | 불로 점수 | 차단 1.2× |
|---|---|---|
| 국내주식 | 22.9 → **14.9** | 25.0% → 33.8% |
| 미국주식 | 6.8 → **5.5** | 40.8% → 47.4% |
| 코인 | 6.8 (유지) | 41.7% (유지) |

### 왜 코인만 빼나 — 국면이 아니라 구조

24시간 거래라 장중 꼬리가 길고 되돌림이 잦다. 고저 폭이 종가 변동보다 계통적으로
크므로 **Parkinson의 전제(장중 평균회귀 없음)가 가장 크게 깨진다.** 실측으로도
P10을 얹으면 중앙비율이 1.13 → 1.27, 차단이 41.7% → 60.0%로 뛰는데 얻는 것은
불로 6.8 → 4.9뿐이다.

미국주식은 이득이 작지만(−1.3점) 함께 간다. 국내·미국을 갈라 두면 **지금 국면을
규칙에 박는 셈**이고, 둘 다 이벤트 구동형 압축-분출이라는 구조는 같다.

### 왜 S20을 안 넣나

국내주식에서 P10 위에 S20을 더하면 불로가 14.9 → 13.7로 1.2점 더 주는 대신
차단이 3.3%p 오른다. P10 한 걸음(−8.0점 / +8.8%p)보다 효율이 나쁘다.

## 장중 꼬리(wick) 방어 — 가장 넓은 하루를 뺀다

외부 검토가 "Parkinson은 ln(H/L)을 쓰므로 순간적으로 찌르고 내려온 꼬리 한 번에
10일간 σ가 비정상적으로 튀고, 유동성이 얇은 종목에서는 의도적으로 만들어 남의
카드를 하한으로 막는 방해가 가능하다"고 지적했다. **실측으로 확인됐다.**

평상시 하루 폭 2%인 종목, 10일 창:

| 하루 꼬리 | σ_P | 최댓값 1개 제외 |
|---|---|---|
| 없음 | 1.20% | 1.20% |
| ±5% 1회 | 2.18% (1.81배) | 1.20% (1.00배) |
| ±10% 1회 | **3.80% (3.16배)** | **1.20% (1.00배)** |
| ±30% 1회 | 10.03% (8.35배) | 1.20% (1.00배) |

**최댓값 하나를 버리면 꼬리가 완전히 사라진다.** 그런데 우리가 잡으려는 진짜 신호는
남는다 — 압축 후 분출은 하루로 끝나지 않기 때문이다:

| 폭 8%인 날 | σ_P | 최댓값 1개 제외 |
|---|---|---|
| 1일 | 1.90% (1.58배) | 1.20% (1.00배) |
| 2일 | 2.40% (2.00배) | **1.96% (1.63배)** |
| 3일 | 2.82% (2.35배) | **2.50% (2.08배)** |
| 5일 | 3.50% (2.92배) | **3.33% (2.77배)** |

의도적 조작이 아니어도 플래시 크래시·오입력 한 건이 같은 일을 한다. 채택했다.

## 남는 것

- **불로 점수를 0으로 만들 수 없다.** 14.6 → 10.0(−32%)이 한계다. 이것은 분포의
  **꼬리** 문제라 중앙을 밀어 올리는 방식으로는 여기까지고, 그 이상은 이벤트 일정
  같은 외부 데이터가 필요하다.
- **이벤트 직전까지 정말 조용한 종목은 통과한다.** 이 추정기는 "이미 흔들리기
  시작했는가"로 대신한다.
- **측정의 한계**: ① 원점을 10거래일 간격으로 옮겨 창이 겹친다 — 관측 496개가
  독립이 아니다 ② 최근 약 460일 **한 국면**만 봤다 ③ 코인 60관측은 적다
  ④ KIS 일봉이 한 번에 300건이라 기한 180일 이상은 재지 못했다
- **"차단 1.2×"는 상한에 가깝다.** 하한이 부풀려진 비율이지 실제로 카드를 못 낸
  비율이 아니다 — 리서처는 목표를 키우면 된다.
- 안정성 눈금은 이 추정기의 분포로 **재캘리브레이션했다**(`npm run calibrate:stability`):
  2.40 / 3.35 / 4.75 / 6.55% → **2.50 / 3.50 / 4.90 / 7.05%**. 옛 눈금을 그대로 뒀다면
  점유율이 ★1:24% ★2:18% ★3:20% ★4:20% ★5:18%로 틀어진다. 이동 폭이 작은 것은
  Parkinson이 장중이 벌어진 종목에서만 걸리고 대형주에서는 거의 binding되지 않기
  때문이다(삼성전자 5.91% → 5.92%).
- 캘리브레이션 표본에서 눈에 띈 것: **국내주식은 거래대금이 클수록 σ가 크다**
  (소형→대형 3.3% → 7.0%). 미국은 반대다(7.5% → 2.4%). 거래대금을 규모 대리변수로
  쓰는 방법의 약점으로 보인다 — 국내에서는 테마 급등으로 거래대금이 폭증한 종목이
  상위 계층에 섞인다. 시가총액이 종목 마스터에 없어 대체할 것이 없다(이전부터 있던 한계).
